**一、必须提供的数据文件**

1. 校园路网数据
2. 建筑面数据
3. POI 点数据
4. 宿舍、教学楼、食堂、校门/出入口等分类数据
5. 校园边界数据
6. 候选停车点数据（如果你已经做了）

**二、文件格式要求**

- 至少给我一份 `GeoJSON`
- 如果方便，再给我一份 `CSV` 便于算法读取
- 坐标系请统一，并明确告诉我使用的是什么坐标系

**三、我对各类数据的字段要求**

**1）路网数据（最重要）**
 每条道路最好至少包含这些字段：

- `road_id`：道路唯一编号
- `start_id`：起点节点编号
- `end_id`：终点节点编号
- `length`：道路长度（米）
- `geometry`：线几何
- `walkable`：是否可通行（1/0）
- `bikeable`：是否适合电单车通行（1/0，如果没有可先默认 1）

如果还没有节点表，也请额外给我：

- 路网节点数据：`node_id, x, y`

**2）POI / 建筑数据**
 每个对象最好至少有：

- `id`：唯一编号
- `name`：名称
- `type`：类型（宿舍 / 教学楼 / 食堂 / 出入口 / 其他）
- `x, y`：坐标
- `geometry`：点或面几何

如果是建筑面数据，希望你能再补充一个代表点字段，或者我可以自己取中心点。

**3）候选停车点数据**
 如果你已经筛过候选停车点，请给我：

- `site_id`：唯一编号
- `x, y`：坐标
- `source`：来源（路口 / 宿舍区门口 / 教学楼附近 / 食堂附近等）
- `available`：是否可作为候选点（1/0）

如果你还没做候选点，可以先给我以下几类基础点，我自己再筛：

- 路口节点
- 宿舍区出入口附近点
- 教学楼门口附近点
- 食堂附近点
- 校门附近点

**4）校园边界数据**

- 校园整体边界 polygon
- 如果有分区边界（生活区、教学区等）也可以一起给我

**四、我对数据质量的具体要求**

1. 坐标系统一，不能一部分经纬度、一部分投影坐标
2. 尽量去重，避免重复 POI
3. 分类字段尽量规范，不要出现“宿舍楼 / dorm / 学生宿舍”混着来
4. 如果能给长度字段就直接给，别让我再从 geometry 重新算
5. 如果有明显不通行路段、封闭区域，请标出来

**五、我最终需要你交付给我的文件**
 最少这几份：

- `campus_roads.geojson`
- `road_nodes.csv` 或 `road_nodes.geojson`
- `buildings.geojson`
- `poi.geojson`
- `candidate_sites.geojson`（如果已有）
- `campus_boundary.geojson`
- 一份字段说明文档（txt/word 都行）
